# Leituras — para continuar depois da aula

Todos os links abaixo foram conferidos antes de entrar nesta lista.

## Documentação oficial

- **[docs.kedro.org](https://docs.kedro.org/en/stable/)** — a documentação
  oficial do Kedro. Ponto de partida para qualquer dúvida técnica.
- **[Tutorial "spaceflights"](https://docs.kedro.org/en/stable/tutorial/spaceflights_tutorial.html)**
  — o tutorial oficial passo a passo (cerca de 30 min), constrói um projeto do
  zero com um dataset de exemplo. Bom próximo passo para quem quiser praticar.
- **[kedro-starters](https://github.com/kedro-org/kedro-starters)** —
  templates oficiais para começar um projeto novo (`kedro new --starter=...`),
  incluindo variações com PySpark, Airflow e Databricks.

## Comunidade

- **[Slack da comunidade Kedro](https://slack.kedro.org)** — canal oficial
  para tirar dúvidas com outras pessoas usando Kedro no dia a dia.
- **[github.com/kedro-org/kedro](https://github.com/kedro-org/kedro)** —
  repositório principal, onde ficam as issues, discussões técnicas e o
  histórico de mudanças de cada versão.

## Sobre o dataset usado na aula

- **[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)**
  (Kaggle) — o dataset usado em todas as demonstrações desta imersão.
  Licença CC BY-NC-SA 4.0. Requer conta Kaggle para download.
